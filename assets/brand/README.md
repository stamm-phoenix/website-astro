# Marken-Quelldateien

Logos und Lilien als Quelldateien. Sie liegen bewusst außerhalb von `web/public/` und werden nicht gebaut oder ausgeliefert.
Soll eine Datei auf der Website erscheinen, wird sie optimiert (z. B. als WebP oder bereinigtes SVG) nach `web/public/` oder `web/src/assets/` kopiert.
